# Rugrats: Search for Reptar (PS1)

Unofficial interest / research repository for a potential static recompilation or decompilation of *Rugrats: Search for Reptar* (PlayStation 1, 1998) by n-Space / THQ.

## Current Status
- **Recomp**: Not started
- **Decomp**: Not started
- Existing research: [lazycurler/RugratsSearchForReptarResearch](https://github.com/lazycurler/RugratsSearchForReptarResearch)

## Purpose
This repo exists to:
- Gauge community interest
- Collect any reverse-engineering notes
- Act as a starting point if someone decides to begin work

## How to show interest
- Star the repository
- Open an Issue with research notes or just to express interest
- Feel free to fork and start documenting

## Legal
This repository contains **no game assets or original code**.  
You must own a legitimate copy of the game.
